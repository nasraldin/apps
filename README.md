## How this repository is organised

Each app has a folder with the same three pages. English is the `README.md` in each folder, and the Arabic version sits next to it in an `ar` folder.

```
money-bank-tracker/
├── README.md            About the app
├── privacy/README.md    Privacy policy
├── privacy/ar/README.md Privacy policy in Arabic
├── support/README.md    Help and contact
└── support/ar/README.md Help and contact in Arabic
```
